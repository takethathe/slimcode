# 04: GFM 表格渲染 + 宽表格横向滚动

**What to build:** assistant 写出的 markdown 表格渲染成真正带边框的表格，单元格内容可读；表格比
转录区宽时在块内横向滚动，而不是把整个转录区撑出横向滚动条。表格是模型回答里最常出现的结构化
内容之一，这也是引入 GFM 的主要理由。

**Blocked by:** 01（markdown 渲染骨架；GFM 扩展随骨架一并接入）。

**Status:** ready-for-agent

- [x] GFM 表格渲染为 `table` 结构（表头/单元格可查询），竖线源文本不出现在可见文本
- [x] 宽表格在块内横向滚动，转录区整体不横向溢出
- [x] 表格边框与内边距与现有浅色体系（slate 描边）一致，不与代码块底色混淆
- [x] DOM 断言覆盖表格结构与单元格文本
