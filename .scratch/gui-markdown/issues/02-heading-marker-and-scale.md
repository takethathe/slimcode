# 02: 标题渲染：保留 `#` 标记，字号只做两档

**What to build:** assistant 回答里的 markdown 标题渲染后，文本前面仍能看到 `#`×N 的字面标记
（弱化为灰色等宽前缀），层级的第一信号是 `#` 的个数而不是字号；字号只做两档装饰——一级二级略大于
正文，三级及以下与正文同号只加粗。一句话：读者不靠字号也能确认"这是二级还是三级标题"。这是 GUI
**有意偏离 TUI/pi**（TUI 丢 `#`、只染色）的地方。

**Blocked by:** 01（markdown 渲染骨架）。

**Status:** ready-for-agent

- [x] `## 小节` 渲染后可见文本同时包含 `##` 与 `小节`，`#` 个数与标题层级一致
- [x] 各级标题用真实的语义标题元素，`#` 前缀与标题字重相互独立（前缀永远是 dim + mono）
- [x] 字号两档：一级/二级略大于正文，三级及以下与正文同号；所有标题加粗
- [x] DOM 断言覆盖一级/二级/三级标题的前缀个数与元素层级
