# 02: SpecStream op 的归约与渐进生长

**What to build:** 把一串到达的 SpecStream op 变成"每张卡当前长什么样"的纯函数归约，并让 UI 在真实渲染里一条条长出来：先出骨架，再出标题、行、徽标。归约要能处理被文本碎片劈开的一行、混进来的坏行、以及多张卡交错到达的情况；渲染按动画帧合批，避免一帧内十几次 React 渲染。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 归约是纯函数：输入为按到达顺序排列的卡片事件与 op 行，输出每张卡的 Spec 与需要的面板状态
- [ ] 被劈开的一行在下一个碎片到达后正确闭合；流结束时残留的不完整行被 flush；坏行被丢弃且不影响随后到达的行
- [ ] 多张卡交错到达时按卡分组互不污染
- [ ] 前端按动画帧合批：一帧内到达的多条 op 只触发一次渲染，视觉上仍连续生长
- [ ] 共享一致性 fixture（一份 op 流 + 期望的最终 Spec）在前端侧被断言，作为跨端一致性的锚点
- [ ] 通过一个调试入口把一串 op 喂进面板，可以肉眼看到逐条生长的过程；无逐字打字机效果
- [ ] 归约的单元测试覆盖：残行、坏行、多卡分组、帧合批；门禁全绿
