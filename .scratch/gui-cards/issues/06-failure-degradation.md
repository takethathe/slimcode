# 06: 失败与降级

**What to build:** 卡片是旁路视图，它的失败不该变成对话的失败。一条 op 都没成功时保留上一版卡片、只在面板内给一个重试入口；某张卡结构出错时只坏那一块，不炸面板；重试与"已在生成"的反馈都在面板内完成，不往 Transcript 或全局错误横幅里塞东西。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 一条 op 都没成功时：上一版卡片保持可见，面板内出现可点的重试入口，结束事件带失败标记
- [ ] 失败信息不进 Transcript、不进全局错误横幅；用户仍可继续对话，下一轮仍会正常触发
- [ ] 单张卡结构错误时由逐元素错误边界与占位降级吸收，同面板其他卡片不受影响
- [ ] 生成中再次请求时给出"已在生成"的明确反馈，而不是静默无效
- [ ] 重试成功后失败提示消失，卡片恢复正常
- [ ] 测试覆盖：零成功 op 的路径、坏卡降级、重试闭环、并发请求被拒的反馈
- [ ] 人工验收：断网或把端点指到不可达地址时，对话仍可用、只有卡片区在提示失败
