# 03: `/new` 与恢复的会话从零计 usage

**What to build:** 用量统计归当前会话所有，而且只活在内存里。`/new` 之后 footer 的 token 数字
归零，用 picker 恢复一个会话之后同样归零（今天恢复后会继续显示**上一个**会话的累计值）；每跑
一轮，把这一轮的 provider 用量累加到当前会话上——一轮里可能发出多次请求，多次都算、且只算一次。
一次性 CLI 没有会话，继续报它自己那次运行的总量。

**Blocked by:** 01

**Status:** resolved

- [x] `/new` 之后两者归零。
